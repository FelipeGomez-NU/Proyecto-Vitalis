## Descripción del proyecto

Vitalis es un centro de acondicionamiento físico que busca optimizar la gestión integral de sus operaciones. 
El proyecto consiste en el análisis y diseño de un sistema enfocado en automatizar y eficientizar la reserva de turnos 
para clases/entrenamientos, integrando además la gestión de pagos y membresías para mejorar la experiencia del usuario
y reducir la carga administrativa.

## Caso de estudio

Caso de estudio: Vitalis (Gimnasio)

Problema: Actualmente, la reserva de turnos y la cobranza de cuotas o pases individuales se realizan
de forma manual o descentralizada, lo que genera ausentismo, solapamiento de horarios y demoras en
el control de pagos.

Solución propuesta: Un sistema web que centralice la agenda de turnos en tiempo real,
permita a los socios reservar y cancelar sus clases de manera autónoma, e integre una
pasarela de pagos para agilizar el cobro y control de membresías.
